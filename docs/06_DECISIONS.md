# Dayjoin 결정·인계 기록

작성일 2026-09-26. 문서 상태는 계획 v0.3이다.

| 구분 | 내용 |
|---|---|
| 사용자 확정 | 이름 Dayjoin, 가족에 한정하지 않는 공유 캘린더, 한국 우선, 주 약 10시간, 프론트 입문, 독립 서비스와 수익화 |
| 추천 | 세 서비스 중 먼저 구현, React/Vite + NestJS/Prisma + Supabase + Cloudflare/Render, 작은 그룹 중심, P0는 단일 일정 |
| 가정 | 첫 시험 그룹 5개를 모집할 수 있음, 이메일 가입 허용, 별도 네이티브 앱 요구 없음 |
| 미결 | 첫 모임 유형, 유료 운영 월 예산, 보유 도메인, 실제 가맹 사업자 조건 |

ADR-D01: 개인 캘린더와 그룹 캘린더는 동일 스키마의 다른 작업 공간으로 격리한다. 실수로 개인 일정이 공개되는 것을 막기 위한 선택이다.

ADR-D02: 외부 양방향 캘린더 연동은 후속 범위다. 토큰/충돌/삭제 동기화가 첫 공유 흐름보다 먼저 커지는 것을 방지한다.

ADR-D03: 반복 일정은 자료 구조를 준비하되 P0 화면에서 약속하지 않는다. 고객 검증으로 우선순위를 바꿀 수 있다.

## 이 프로젝트에서 이어서 할 작업

1. README와 PRD를 읽고 D-001~006을 순서대로 시작한다.
2. 기술 환경을 점검한 뒤 버전을 고정하고 첫 화면을 구현한다. 기존 파일이 생겼다면 보존하고 현재 상태에 맞춰 작업한다.
3. 실제 완료할 때만 백로그를 체크하고 검사 로그를 기록한다.
4. 공통 계획 변경은 다른 서비스에 자동 덮어쓰지 않고 영향과 이유를 각 결정 기록에 남긴다.

현재 수행한 것은 프로젝트 확인, 공식 기술/비용 조사, 계획 문서 작성이다. 개발·운영 계정 가입·배포·결제·상표/도메인 검증은 수행하지 않았다.

## ADR-N01 · 백엔드 계획 변경 / 2026-09-26

사용자가 TypeScript·NestJS를 가장 많이 사용했고 Python은 조금 사용했다고 확인했다. 백엔드를 NestJS로 정하고 Java/C# 신규 학습은 출시 계획에서 제외한다. 기존 v0.1의 브라우저→Supabase 업무 조회/RPC와 Edge Functions 중심 설계를 대체한다.

업무 API·권한·트랜잭션·외부 호출은 Nest, DB/인증은 Supabase, 화면은 React/Vite로 나눈다. Prisma는 ORM/migration 추천안이다. API 컨테이너 배포와 비용을 추가하고 인증/RLS 통합 시험을 기반 작업에 포함한다. Python은 필요할 때 오프라인 데이터 실험에 사용하며 별도 서버 추가는 실제 요구 확인 후 결정한다.

당시 변경은 계획 v0.2였다. 제품의 v0/v0.1 범위와 베타 목표는 유지한다. 공수는 Nest 경험이 확정되었다고 임의로 줄이지 않고, 프론트 학습과 API 운영/RLS 검증을 포함해 첫 2주 후 다시 산정한다. API/DB 접근 기반이 추정을 넘으면 기능 범위와 일정을 함께 조정한다. 이 변경은 앱 구현이나 클라우드 계약 완료를 뜻하지 않는다.

## 2026-09-26 · v0.3 공식 문서/CLI 개발 원칙

사용자가 React + Vite / NestJS, 터미널 설치·생성·검증, 공식 문서 확인, PostgreSQL·Redis·Compose·모듈화를 포함한 DevOps 검토를 확정했다.

로컬 개발은 Compose PostgreSQL을 기본으로 하고 Redis를 cache profile로 선택한다. Supabase Auth/관리형 운영 구성은 인증 단계에서 결정한다. 공식 필수 조건과 프로젝트 선택을 구분한다. Dayjoin에서 기반을 먼저 검증하고 Cashjoin·Workjoin은 같은 원칙을 적용한 계획 상태로 유지한다.

## 후속 확정 · 세 프로젝트 기초 세팅 후 새 채팅

사용자가 세 프로젝트 모두 기초 세팅까지만 완료하고 각 프로젝트의 새 채팅에서 하나씩 진행하기로 정했다. 공통 기반·독립 포트/DB/volume·빌드/연결 검증을 완료했다. 인증·제품 기능은 이번 범위에서 시작하지 않는다. 현재 상태와 다음 후보는 docs/11_CHAT_HANDOFF.md가 기준이다.
